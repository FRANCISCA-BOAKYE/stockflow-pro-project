# StockFlow Pro

**A Supply Chain and Business Management Platform**

StockFlow Pro is a cross-platform business management system designed to streamline operations for manufacturers, wholesalers, and retailers. It brings essential business processes together, helping businesses manage inventory, production, sales, customer credit, and financial transactions in one connected platform.

The project combines a Next.js web application, a React Native mobile application, a Spring Boot backend, and a PostgreSQL database to support efficient and consistent business operations.

## Key Features

* **Inventory Management:** Manage products, raw materials, stock levels, and inventory movements.
* **Production Management:** Track production activities, material usage, and finished products.
* **Sales Management:** Record sales transactions and support different business workflows.
* **Customer Credit Management:** Track credit sales, customer balances, and outstanding payments.
* **Automated Invoicing:** Generate and manage invoices for business transactions.
* **Subscription Management:** Manage subscription plans and associated payment records.
* **Payment Integration:** Integrate Paystack to support online payment processing.
* **Email Notifications:** Use Gmail integration to send relevant order and invoice updates.
* **Role-Based Access Control:** Restrict access to business information and operations according to user permissions.
* **Cross-Platform Access:** Support business operations through web and mobile applications.

## Technology Stack

**Frontend:** Next.js, React, TypeScript, Tailwind CSS, React Native

**Backend:** Java, Spring Boot

**Database:** PostgreSQL, Neon

**Integrations:** Paystack for payment processing and Gmail for email notifications

**Version Control:** Git and GitHub

## System Architecture

StockFlow Pro uses a shared backend architecture in which the web and mobile applications communicate with a Spring Boot API. The backend manages business logic, validates requests, enforces access permissions, and interacts with the PostgreSQL database.

This architecture helps maintain consistent business rules and data across both platforms while supporting integrations with external services.

## Target Users

StockFlow Pro is designed for:

* **Manufacturers** who need to manage raw materials, production, and finished goods.
* **Wholesalers** who need to manage inventory, bulk sales, customer credit, and invoicing.
* **Retailers** who need to track products, sales, stock levels, and customer transactions.

## Project Goals

The main goal of StockFlow Pro is to simplify business operations by connecting inventory, production, sales, and financial management in one platform. It aims to reduce manual recordkeeping, improve transaction tracking, and provide businesses with better visibility into their operations.
